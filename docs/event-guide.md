# Event Guide: Harness Engineering & Model Wrangling #SFTechWeek Hackathon

Shack15, 1 Ferry Building Suite 201, San Francisco. Sunday, Oct 11 2026.
Hosted by MongoDB with Cerebral Valley.

## Problem statements (project must fit at least one)

**Statement 1: Recursive Harnessing** (AgentShield targets this one)
Build a self-improving agent harness that automatically evolves its own architecture: updating rules, context policies, guardrails, tool access, and more. How can agents dynamically adapt their entire environment to fit a specific user, task, or use case?

**Statement 2: Long Horizon Engineering**
The highest-value agentic work spans hours, days, or weeks. Build a harness that sustains coherent memory across billions of tokens in one session, relentlessly optimizes toward long-term goals, and learns from hard metric signals to complete traditionally difficult tasks.

## Hard rules

- **Atlas Sandbox required:** finalists must build on the MongoDB Atlas Sandbox cluster from the hackathon email. Otherwise not eligible for finals or prizes.
- **Public repo** required.
- **Team size:** max 4, solo allowed.
- **Demo only what was built today.** Judges must clearly see what was created at the event, or it is an immediate disqualification.
- **New work only.** No existing projects.
- **Banned:** anything violating legal, ethical, or platform policies, or using code, data, or assets you do not have rights to.

## Anti-projects (strictly not allowed)

AI mental health advisor, basic RAG apps, **Streamlit apps**, image analyzers, "AI for Education" chatbot, AI job application screener, AI nutrition coach, personality analyzers, anything giving medical advice, **any project where a dashboard is the main feature**, sports analyzers or coaches.

## Submission

- Submit through the Cerebral Valley form.
- **1-minute demo video** showing the specific features, code, and functionality built today.
- Check: repo is public, demo link works, all team members added.

## Judging

Round 1: ~3 min live demo + 1-2 min Q&A.

| Criterion | Weight |
|---|---|
| Technical Demo (impressive, well-engineered, working) | 35% |
| Implementation Difficulty (more than a few prompts away) | 30% |
| Impact Potential (real-world pain point) | 20% |
| Creativity (never seen before) | 15% |

Round 2 (top 6 on stage): same criteria, equal weighting.
